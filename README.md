# 안성고등학교 신입생 안내 챗봇

학교 기본정보·시설·일과·생활규정·2027학년도 입학전형에 관한 질문 65개를 검색하는 터미널 MVP입니다.
Python 3.9 이상과 표준 라이브러리만 사용하며 API 키나 패키지 설치가 필요하지 않습니다.

## 실행

```powershell
python chat.py
```

예시 질문: `급식실 어디야?`, `등교 시간`, `체육복 입어도 돼?`, `휴대폰`

- `목록`: 전체 질문과 선택 번호 표시
- `도움말`: 사용 방법 표시
- 여러 결과가 나오면 번호로 선택하거나 새 질문 입력
- `0`: 선택 취소
- `종료`, `끝`, `exit`, `quit`: 프로그램 종료

답변 내용만 표시하며 출처, 확인 날짜와 자료 상태는 데이터에 보관합니다. 질문은 저장하지 않습니다.
현재는 키워드 검색 방식이며 외부 생성형 AI, 실시간 정보 조회, 오타 자동 교정을 지원하지 않습니다.
검색이 안 되면 짧은 핵심 단어로 질문하거나 목록에서 선택하세요.

## 자료

- [FAQ 데이터](data/faq.json): 질문·키워드·답변·출처·확인 날짜·상태·분류
- [학교 자료 정리](data/school_notes.md): 자료의 근거와 보류 항목
- [PDF 추출 텍스트](data/regulations_extracted.txt): 페이지별 참고본. 표의 열 배치는 원본 PDF 확인 필요

이 MVP는 사용자가 제공한 자료를 바탕으로 만든 시제품입니다.
시설과 기본정보는 공식 확인 전 참고용 초안이며, 일과는 사용자 제공 정보입니다.
규정은 제공 PDF 본문을 확인했지만 최신 시행 여부까지 확인한 것은 아닙니다.
16:40 수업 종료는 점심시간이 4교시 직후 시작해 60분 뒤 5교시가 시작한다고 계산한 결과입니다.
학교가 확정한 공식 안내 서비스로 배포하기 전에 최신 자료와 대조해야 합니다.

## 검증

구문 검사: `python -m py_compile chat.py`

사용자의 요청에 따라 테스트 파일은 두지 않았습니다. MVP 개발 시 임시 unittest로
65개 질문의 검색, 출처 표시, 미등록 질문, 후보 선택, 잘못된 번호, 입력 중단과 종료를 검증했습니다.



입학전형 정리: [2027학년도 신입생 입학전형](data/admissions_2027.md). 사용자 제공 모집요강 발췌 기준이며 공식 게시본과 변경 공지는 별도 확인이 필요합니다.
